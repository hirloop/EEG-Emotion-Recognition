# EEG情绪识别：基于Lasso逻辑回归与SVM模型

## 📌 项目简介
本项目旨在利用脑电（EEG）信号，预测被试所观看情绪图片的情绪类别（负性 vs 中性）。项目使用**L1正则化逻辑回归（Lasso）** 进行特征选择与分类，并采用**留一被试交叉验证（LOSO-CV）** 来评估模型的泛化能力，最后对比了使用高被选特征训练的SVM模型效果。

## 📂 数据准备

### 1. 数据来源与实验设计
- **原始数据**：40名被试观看情绪图片时的EEG数据（已预处理，去伪迹、滤波）。
- **实验流程**：图片呈现 3 秒，分析窗口为刺激前 -200 ms 至刺激后 3000 ms。
- **特征提取**：
  - **PSD特征**：提取 -200 ms 至 3000 ms 窗口内的 **θ (4–8 Hz)、α (8–13 Hz)、β (13–30 Hz)** 三个频段的 **功率谱密度（PSD）** ，并取对数（`10*log10`）。
  - **波幅特征**：提取 400–600 ms 窗口内的**平均波幅**（单位：μV）。
- **数据维度**：最终整理为 `2998 × 91` 的矩阵，保存为 `.mat` 文件。
  - 第1列：被试ID
  - 第2–85列：84个PSD特征（28通道 × 3频段）
  - 第86–90列：5个波幅特征
  - 第91列：标签（1 = 负性，0 = 中性）

### 2. 特征通道与顺序说明
- **PSD特征通道（28个，按列顺序）**：
  `AF3, AF4, F3, F1, Fz, F2, F4, CP1, CPz, CP2, P3, Pz, P4, POz, O1, Oz, O2, T7, T8, TP7, TP8, C3, C1, Cz, C2, C4, CP3, CP4`

- **波幅特征通道（5个，按列顺序）**：
  `P3, P4, Pz, CPz, POz`

### 3. 数据标准化策略：被试内 Z-score
由于EEG信号存在极大的个体差异，我们采用了**被试内标准化（Within-Subject Z-score）**：
- **做法**：对每一位被试的所有试次，分别对每一列特征进行 Z-score 标准化。
- **目的**：消除个体间的绝对功率差异，保留个体内的相对变化模式，从而让模型学习“跨被试通用的情绪相关脑电模式”。

## 🤖 模型训练

### 1. 模型选择：L1正则化逻辑回归（Lasso）
- **工具**：Matlab `lassoglm` 函数
- **参数设置**：
  - `Alpha = 1`：纯 L1 正则化（Lasso），产生稀疏解，自动筛选重要特征。
  - `CV = 5`：在训练集内部进行 5 折交叉验证，自动选择最优的 `Lambda`（正则化强度）。
  - `Standardize = false`：因为已手动进行被试内标准化，避免重复。
- **原理**：Lasso 通过惩罚系数的绝对值之和，将不重要特征的系数压缩为零，从而实现自动特征选择。

### 2. 评估策略：留一被试交叉验证（LOSO-CV）
- **流程**：
  - 共40名被试，每次留出1名被试作为测试集，其余39名作为训练集。
  - 训练集内部进行 5 折交叉验证选择最优 `Lambda`。
  - 测试集用于评估模型性能。
- **目的**：模拟“新被试”场景，检验模型是否能跨被试泛化，避免同一被试试次泄露导致的准确率虚高。
- **模型数量**：共训练 40 个独立的 Lasso 模型。

### 3. 预测时，逻辑回归的 `score` 为什么不在 (0,1) 之间？
- `lassoglm` 输出的 `score = X*w + b` 是**线性预测值**，范围是 (-∞, +∞)。
- 要得到概率值，需要手动做 Sigmoid 变换：`prob = 1./(1 + exp(-score))`。
- 分类时，`score > 0` 等价于 `prob > 0.5`。

### 1. 整体性能（Lasso + LOSO-CV）
- **平均准确率**：60.38% (± 6.23%)
- **总体准确率**：60.47%
- **AUC**：0.653
- **二项检验**：p < 0.0001（显著高于随机水平50%）
- **平均选中特征数**：44.1 / 89

### 2. 混淆矩阵分析（Lasso + LOSO-CV）
|  | 预测中性 | 预测负性 |
|---|---|---|
| **真实中性** | 904 | 588 |
| **真实负性** | 597 | 909 |

**分析**：模型在中性和负性两类上的预测较为均衡（中性召回率60.6%，负性召回率60.3%），没有出现严重的类别偏置。

### 3. 特征稳定性分析
- 统计了每个特征在40个被试的Lasso模型中被选中的次数。
- **Top 40特征**在所有40个被试中均被选中，表明这些通道-频段组合是跨被试非常稳定的情绪标记物。

### 4. SVM 对比实验（初步）

为了对比线性 Lasso 与非线性模型的表现，我额外做了一个简单的 SVM（RBF 核）实验。  

**实验设置：**
- 测试集大小：599 个试次（随机划分）
- 对比两种特征集：
  1. 全部 89 个特征
  2. Lasso 中被被试选中次数最多的前 40 个特征

**结果：**

| 特征集 | 混淆矩阵（真实行 × 预测列） | 测试集准确率 | 中性召回率 | 负性召回率 |
|--------|----------------------------|--------------|------------|------------|
| 全部 89 特征 | `[170 130; 102 197]` | **61.27%** | 56.67% | 65.89% |
| Lasso 前 40 特征 | `[182 118; 108 191]` | **62.27%** | 60.67% | 63.88% |

> 混淆矩阵格式：第一行 = 真实中性(0)，第二行 = 真实负性(1)；第一列 = 预测中性，第二列 = 预测负性。

**初步结论：**
- 使用 Lasso 筛选出的前 40 个特征后，SVM 准确率从 61.27% 提升到 62.27%，**略有提升（约 1 个百分点）**。
- 两类召回率更加均衡：中性召回率从 56.67% 提升到 60.67%，负性召回率从 65.89% 略降到 63.88%。
- 整体来看，SVM 与 Lasso 逻辑回归的性能差别不大，说明在当前特征集下，线性模型已经能捕捉到主要的信息；非线性模型带来的增益有限。
- 注意：随机划分可能导致同一被试的试次同时出现在训练和测试集中，从而高估泛化性能。后续如需严谨对比，应改用 **LOSO-CV** 或按被试分组划分。
